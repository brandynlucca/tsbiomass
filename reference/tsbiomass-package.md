# Native routines used by tsbiomass

Bundles the TS-model transferability analysis pipeline, benchmark logic,
admissibility screening, uncertainty benchmarking, sensitivity analyses,
and figure-generation pipeline used for TS-to-biomass transfer analyses.
The package is configuration-driven and can be run from YAML/JSON files
or from the preserved command-line interface.
