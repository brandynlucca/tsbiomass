# Policy prediction bundle

Stores the full policy-interval table, the retained selected-policy
rows, and the donor-pool consensus summaries returned by
[`predict()`](https://rdrr.io/r/stats/predict.html) on a
[PolicySelector](https://brandynlucca.github.io/tsbiomass/reference/PolicySelector-class.md).

## Examples

``` r
if (FALSE) { # \dontrun{
predictions <- predict(selector)
predictions
predictions
predictions
} # }
```
