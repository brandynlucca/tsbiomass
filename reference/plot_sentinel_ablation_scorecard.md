# Plot paired Sentinel ablation importance from a Scorecard

Plot paired Sentinel ablation importance from a Scorecard

## Usage

``` r
plot_sentinel_ablation_scorecard(x, labels = NULL, title = NULL)
```

## Arguments

- x:

  A Sentinel-ablation
  [Scorecard](https://brandynlucca.github.io/tsbiomass/reference/Scorecard-class.md).

- labels:

  Optional named character vector mapping scenario names to display
  labels.

- title:

  Optional plot title.

## Value

A ggplot object.
