# Plot the Sentinel ablation decomposition

Plot the Sentinel ablation decomposition

## Usage

``` r
plot_sentinel_ablation_decomposition_scorecard(x, labels = NULL)
```

## Arguments

- x:

  A Sentinel-ablation-decomposition
  [Scorecard](https://brandynlucca.github.io/tsbiomass/reference/Scorecard-class.md).

- labels:

  Optional named character vector mapping scenario names to display
  labels.

## Value

A ggplot object.
